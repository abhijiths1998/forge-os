# Forge Wallpapers

The wallpaper app for Forge OS on Hyprland. Shows a grid of the bundled
Forge cast wallpapers, with tabs for online sources (Wallhaven, NASA APOD,
Unsplash/Pexels) — the UI can list images but fetching keys and download
logic are stubbed for now.

- Arrow keys move, Enter or Space applies, Esc quits.
- Tabs switch between the Forge cast grid and each online source.
- `forge-wallpapers` sets the wallpaper through swww/awww (placeholder,
  not yet wired — not verified on hardware).

The cast wallpapers are generated by `branding-source/cast/generate.py`
from the 8 original Forge cast SVGs: Shonen Fighter, Mecha Pilot,
Wandering Ronin, Magical Girl, Cyberpunk Hacker, Yokai Guardian, Sky
Pirate, Idol Singer.

```sh
flutter analyze && flutter test
flutter build linux --release --no-tree-shake-icons
```

Not tested on hardware: the swww/awww integration and daily rotation.

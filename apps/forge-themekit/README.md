# Forge Theming Kit

Themes for the Forge Glass desktop, and sliders for everything that makes
one: pick a built-in theme (Forge Glass, Forge Glass Light, Frost, Liquid
Bold, Midnight, Ember, Aurora, Mint, Rosé) or one you saved, or shape your
own.

| Group | Controls |
|---|---|
| Colour | dark or light, accent, glass tint (hue) and tint strength |
| Liquid glass | blur, vibrancy, lens width, lens strength, edge bevel, inner bending, colour split, grain |
| Surfaces | window, menu/toolbar and terminal opacity |
| Shape | window corner radius |

Changes go straight to the desktop (`lib/apply.dart`):

- **Glass and shape** (as sliders move): KWin's Glass and rounded-corners
  effects (`kwinrc`) and Darkly's titlebar corners, then the effects
  reload. Nothing ever draws a coloured border: edge lighting, rim light
  and outlines stay off.
- **Colour and surfaces** (when a slider is released): a KDE colour scheme
  (`ForgeKitA`/`B`, generated by forge_ui in colors.py's format), icons for
  light or dark, Darkly's menu opacities (apps opened afterwards pick them
  up), Konsole's ForgeGlass scheme, and `~/.config/forge/theme.json`, which
  the Forge apps (launcher, store) read for their own colours.

Saved themes are `~/.config/forge/themes/*.json`; a theme file can be
shared and applied with `forge-themekit --apply <file.json>`.

```sh
forge-themekit                   # the kit
forge-themekit --apply ember     # a theme by id or name, or a .json file
forge theme ember                # the same, from the forge command
```

The theme model, palette, scheme generation and widgets are in
`../forge_ui`; its test checks that the Forge Glass themes reproduce the
shipped colour schemes exactly.
